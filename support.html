Mes parties et mes pièces

Ça tient ? fonctionne sans compte de jeu. Vos réglages, pièces, records et contenus débloqués sont enregistrés localement sur votre appareil.

Avant de désinstaller le jeu ou de changer d’appareil pour résoudre un problème de sauvegarde, contactez l’assistance. Restaurer un achat Apple ne restaure pas nécessairement votre progression locale.

Un problème avec un achat ?

Les achats intégrés facultatifs sont traités par Apple via l’App Store. Le jeu ne reçoit pas vos informations de paiement.

Vérifiez que vous utilisez le compte Apple ayant servi à l’achat. Pour retrouver un achat restaurable, consultez l’aide Apple sur la restauration des achats intégrés. Si le problème persiste, écrivez-nous en précisant l’achat concerné et ce qui s’affiche dans le jeu.

Ne transmettez ni coordonnées bancaires, ni mot de passe, ni code de connexion.

Publicités et confidentialité

Le jeu peut afficher des vidéos récompensées facultatives et, le cas échéant, des annonces interstitielles via Google AdMob.

Dans les régions concernées, le jeu demande le consentement requis avant de diffuser des publicités personnalisées. Lorsque cette option est requise par Google, utilisez « Choix publicitaires » dans la boutique pour revoir vos préférences.

Les informations détaillées sont disponibles dans la politique de confidentialité. Si une vidéo ne se lance pas ou si une récompense semble manquer, indiquez-nous les étapes suivies et ce qui s’est affiché.

Ce qui arrive avec la version 1.1

La version 1.1 prévoit 8 pièces, 5 modes, un défi quotidien, 24 défis conçus à la main, des décorations locales, la reprise de partie et le partage facultatif de vidéos de replay via iOS.

La Collection Atelier

Cet achat permanent, traité par Apple avec StoreKit, supprime les publicités automatiques et ajoute trois couleurs cosmétiques. Il est restaurable depuis la boutique, avec « Restaurer les achats », avec le compte Apple utilisé pour l’achat. Les vidéos récompensées restent facultatives. Aucun pack de pièces payant n’est prévu.

Les sauvegardes et les données

Les données de jeu resteront locales, sans compte de jeu ni synchronisation par un serveur du jeu. Le portefeuille et les événements de récompense seront conservés dans le trousseau iOS pour éviter les doubles crédits. Désinstaller l’app ne garantit pas l’effacement de ces éléments.

La version 1.1 ne prévoit pas d’analyse des parties sur un serveur du jeu. Les annonces utiliseront Google AdMob et les demandes de consentement publicitaire seront gérées avec Google UMP lorsqu’elles sont applicables.

Quelque chose ne tient pas ?

Pour nous aider à comprendre un blocage, précisez la version du jeu, votre modèle d’iPhone, la version d’iOS et les étapes permettant de reproduire le problème.
